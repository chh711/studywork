1.•什么情况下值得为数据建一个类？“字典 + 函数”方案的边界在哪？
字段之间有限制？   → 类
函数总绑着这数据？ → 类
出现了类型分发？   → 类
只是搬砖传数据？   → 字典
字段名不确定？     → 字典

当超过 2~3 个函数共享同一数据结构作为首要参数时 → 建类
出现 if type == ... 或 isinstance 分发时 → 建类
当"字典 + 函数"让你开始写重复代码或者担心数据被破坏时，就该建类了。

2.点乘的几何意义是什么？两个向量点乘为 0 说明什么？

几何定义（这才是核心）

a * b  = //a// *// b// * cosθ 
 
两向量正交 / 垂直 

点乘为 0 这个性质在实际中被大量使用：

特征无关：两个特征向量的点乘为 0，说明它们在向量空间中相互独立、不携带重叠信息
PCA / 正交分解：主成分之间互相正交，保证每个成分捕捉的是独立的变化方向
傅里叶变换：不同频率的正弦波相互正交，互不干扰
注意力机制：Transformer 中 ,就是用点乘度量 query 和 key 之间的相似度——点乘越大，说明 token 之间越相关

3.•为什么矩阵乘法不满足交换律？从“变换”的角度解释。
矩阵乘法不满足交换律，是因为变换的顺序决定了每一步面对的是什么样的空间——先做的变换会改变整个坐标系的形态，后做的变换只能在这个已被改变的空间上操作。这就好比你无法在"把墙推倒"和"在
墙上挂画"之间随意交换顺序
